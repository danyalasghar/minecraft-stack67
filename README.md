# Stack 67
[Modrinth Link](https://modrinth.com/mod/stack67) | [Curseforge Link](https://modrinth.com/mod/stack67) | [Contact Dev](https://guns.lol/danify)


A lightweight Fabric mod for Minecraft that bumps the default maximum item stack size from 64 to 67. The mod utilizes `DefaultItemComponentEvents` from the Fabric API inside of a basic mod initializer file. It passes a predicate into the `context.modify()` method that checks if an item's default maximum stack size is 64. If the condition is matched, the item will have its `DataComponents.MAX_STACK_SIZE` updated to 67

## Setup
1. Make sure you have the Fabric Loader installed for your Minecraft version.
2. Install the Fabric API into your minecraft's `mods` folder.
3. Download the latest release of the mod and place the `.jar` file into your `mods` folder.
4. Launch the game!
